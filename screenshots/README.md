# 首页配图维护

现有界面图位于本目录。首页使用相对路径，主要截图两张一行。

待补 3 张：

- `enhancement-comparison.svg`：同帧原画 / 增强后对比。标注显卡、分辨率、帧率、插帧开关及超分档位；不要用不同镜头代替效果对比。
- `themes-overview.svg`：21 主题总览。使用同一页面制作缩略图拼版，标注主题名，可按深浅色分组。
- `effects-overview.svg`：9 种动态背景。建议 3×3 拼图或 GIF，逐项标注名称。

替换为 JPG / PNG / GIF 时，上传到本目录，并修改根目录 README 中对应 `img` 的 `src`、`alt` 和“配图待补”图注。文件名使用英文，避免空格。SVG 目前只是占位图，不是增强效果示例。
